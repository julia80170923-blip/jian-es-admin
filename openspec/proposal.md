# 吉安國小特教行政網站 OpenSpec 提案說明 (Proposal)

## 專案簡介 (Project Overview)
「吉安國小特教行政網站」為花蓮縣吉安國民小學專屬之特教資訊門戶。專案採用 **OpenSpec (Spec-Driven Development, SDD)** 開發規範，將系統需求、架構設計與測試情境文檔化與機讀化，協助特教團隊與普通班導師高效率管理特教資源班、IEP 個別化教育計畫、轉介前介入與核心特教門戶跳轉。

## 專案目標 (Project Goals)
1. **三大發布目標版面 (3 Target Sections for Dynamic Pages)**：
   特教人員可在後台彈性選擇發布網頁至：
   - **🌐 網站連結庫 / 公開特教專區**（全校師生與家長皆可瀏覽）
   - **🍎 導師專區**（專為普通班導師設計之實用指引與資源，所有人可瀏覽）
   - **🔒 校內特教業務版面**（需密碼 `8523984` 解鎖方可瀏覽）
2. **網頁畫面內嵌與外跳設定 (Webpage Embedding & External Redirect)**：
   - **內嵌顯示 (iframe)**：能在文章中直接嵌入並即時呈現外部目標網站內容畫面。
   - **直接外跳 (External URL)**：可設定點擊該網頁選單時，直接跳轉開啟目標網站。
3. **純動態網頁驅動與舊靜態卡片清理 (Pure Dynamic Page Rendering)**：
   全站版面皆由管理控制台動態維護。
4. **管理控制台與校內版面雙重密碼防護 (Dual Password Security)**：
   進入「校內特教業務版面」與「管理控制台」均強制實施密碼驗證（驗證密碼為 `8523984`）。

## 使用者角色與情境 (User Personas & Scenarios)
- **普通班導師 (General Teacher)**：於首頁「導師專區」瀏覽由特教團隊發布之轉介前介入指引與內嵌之評量表單。
- **特教資源班教師與行政人員 (Special Ed Staff)**：開啟控制台，點擊 `[ 內嵌網頁 (iframe) ]` 快捷按鈕嵌入網站畫面或填寫外跳網址。
