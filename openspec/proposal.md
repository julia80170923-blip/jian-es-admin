# 吉安國小特教行政網站 OpenSpec 提案說明 (Proposal)

## 專案簡介 (Project Overview)
「吉安國小特教行政網站」為花蓮縣吉安國民小學專屬之特教資訊門戶。專案採用 **OpenSpec (Spec-Driven Development, SDD)** 開發規範，將系統需求、架構設計與測試情境文檔化與機讀化，協助特教團隊高效率管理校內特教資源班、IEP 個別化教育計畫、專團與巡迴輔導服務、考試服務評量調整與外部特教公務連結。

## 專案目標 (Project Goals)
1. **精簡特教核心連結 (Centralized Special Ed Core Links)**：
   專載 4 大官方核心特教門戶（教育部特教通報網、全國教師在職進修網、花蓮縣特教資源網、教育部特教資訊網-研習報名）。
2. **零負擔託管與資安個資保護 (Zero-Leak Security & Hosting)**：
   託管於 GitHub Pages / Netlify 平台（完全免費且無流量額度限制），所有特教資料皆採用純前端機制存取與加密，防範任何個資外洩風險。
3. **校內特教業務密碼防護專區 (Internal Password Protected Section)**：
   建置校內特教業務版面，進入需輸入安全性驗證密碼（預設為 `8523984`），保護敏感特教表單與校內事項。
4. **自訂網頁版面歸類選擇 (Target Section Selection)**：
   特教人員新增動態網頁時，可彈性選擇發布至「公開網站連結庫/特教專區」或「校內特教業務版面」。

## 使用者角色與情境 (User Personas & Scenarios)
- **特教資源班教師 (Special Ed Teacher)**：發布 IEP 填寫指引、管理校內特教專區與內部業務文件。
- **普通班導師 (General Teacher)**：輸入密碼 `8523984` 進入校內版面，查閱學生轉介前介入流程、下載特教觀察表格與申請特殊考試服務。
- **家長與學生 (Parents & Students)**：瀏覽資源班簡介、公開特教外部連結與特教宣導。

## 成功指標 (Success Metrics)
- 個資零外洩、零後端伺服器資安維護負擔。
- 校內特教業務版面 100% 進行密碼防護。
- 新增/更新特教網頁可在 1 分鐘內即時分類上線。
