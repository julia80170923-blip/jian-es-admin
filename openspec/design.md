## 資料模型規格 (Data Models Schema)

### 1. 特教動態網頁與外跳網站 (Dynamic Page Schema)
```json
{
  "id": "page-custom-1786584900000",
  "title": "特生考試服務服務雲",
  "slug": "special-exam-service-cloud",
  "category": "資源班專區",
  "targetSection": "internal",
  "externalUrl": "https://regal-tiramisu-ecaf8b.netlify.app/",
  "content": "點擊上方按鈕自動跳轉至「特生考試服務服務雲」官方網站。",
  "isPublished": true,
  "updatedAt": "2026-08-13"
}
```
*當 `externalUrl` 存在或使用者直接貼上完整 URL 時，前台自動生成醒目的【網站名稱按鈕】，點擊後自動在新視窗跳轉開啟目標網頁。*
