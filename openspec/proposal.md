# 吉安國小特教行政網站 OpenSpec 提案說明 (Proposal)

## 專案簡介 (Project Overview)
「吉安國小特教行政網站」為花蓮縣吉安國民小學專屬之特教資訊門戶。專案採用 **OpenSpec (Spec-Driven Development, SDD)** 開發規範，將系統需求、架構設計與測試情境文檔化與機讀化，協助特教團隊與普通班導師高效率管理特教資源班、IEP 個別化教育計畫、轉介前介入與核心特教門戶跳轉。

## 專案目標 (Project Goals)
1. **手機版三條橫線按鈕與抽屜選單修復 (Mobile Toggle & Menu Fix)**：
   重構手機端導覽列，消除空間擠壓，確保右上角三條橫線按鈕 100% 顯眼可點擊；點開後完整提供「首頁」、「校內特教業務」與「管理控制台」三項功能。
2. **全裝置自適應 (Responsive Web Design, RWD)**：
   全站與管理控制台全面支援手機、平板、小筆電、大螢幕桌機與 4K 螢幕自適應縮放，確保在任何裝置上均提供最佳瀏覽體驗。
3. **控制台刪除雙重防護 (`id, index`)**：
   管理控制台刪除按鈕導入 ID ＋ 陣列索引雙重扣除機制，保證點擊任何表格列的 `[ 🗑 刪除 ]` 按鈕時，100% 精準秒級刪除該筆資料。
4. **三大發布目標版面 (3 Target Sections)**：
   支援選擇發布至 `🌐 網站連結庫/公開專區`、`🍎 導師專區`、或 `🔒 校內特教業務版面`。

## 使用者角色與情境 (User Personas & Scenarios)
- **手機端使用者**：在智慧型手機上輕鬆點開右上角三條橫線按鈕，無障礙切換至「校內特教業務」版面並輸入密碼解鎖。
