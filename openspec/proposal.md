# 吉安國小特教行政網站 OpenSpec 提案說明 (Proposal)

## 專案簡介 (Project Overview)
「吉安國小特教行政網站」為花蓮縣吉安國民小學專屬之特教資訊門戶。專案採用 **OpenSpec (Spec-Driven Development, SDD)** 開發規範，將系統需求、架構設計與測試情境文檔化與機讀化，協助特教團隊與普通班導師高效率管理特教資源班、IEP 個別化教育計畫、轉介前介入與核心特教門戶跳轉。

## 專案目標 (Project Goals)
1. **三大發布目標版面 (3 Target Sections for Dynamic Pages)**：
   特教人員可在後台彈性選擇發布網頁至：
   - **🌐 網站連結庫 / 公開特教專區**（全校師生與家長皆可瀏覽）
   - **🍎 導師專區**（專為普通班導師設計之實用指引與資源，所有人可瀏覽）
   - **🔒 校內特教業務版面**（需密碼 `8523984` 解鎖方可瀏覽）
2. **純動態網頁驅動與舊靜態卡片清理 (Pure Dynamic Page Rendering)**：
   移除所有預設之硬編碼靜態卡片，全站版面皆由管理控制台動態維護。
3. **前台權限收斂 (Streamlined Admin Access)**：
   移除前台直接發布網頁按鈕，所有網頁與連結新增作業統一由 `⚙️ 管理控制台` （雙重密碼 `8523984`）安全控管。
4. **零負擔託管與資安個資保護 (Zero-Leak Security & Hosting)**：
   託管於 GitHub Pages 平台（完全免費且無流量額度限制），所有特教資料皆採用純前端機制存取與加密。

## 使用者角色與情境 (User Personas & Scenarios)
- **普通班導師 (General Teacher)**：於首頁「導師專區」瀏覽由特教團隊發布之轉介前介入指引與考試服務申請文章。
- **特教資源班教師與行政人員 (Special Ed Staff)**：輸入密碼 `8523984` 開啟管理控制台，新增或編輯網頁並指定歸類版面。
- **家長與學生 (Parents & Students)**：瀏覽資源班簡介、公開特教核心門戶與宣導資料。
