## 資料模型規格 (Data Models Schema)

### 1. 特教動態網頁 (Dynamic Page Schema)
```json
{
  "id": "page-sp-101",
  "title": "115學年度IEP個別化教育計畫會議流程與指引",
  "slug": "iep-guidelines",
  "category": "IEP個案管理",
  "targetSection": "public", 
  "content": "## IEP 會議時程與填寫指引\n...",
  "isPublished": true,
  "updatedAt": "2026-08-13"
}
```
*`targetSection` 支援 `"public"` (公開專區/連結庫) 與 `"internal"` (校內特教業務版面)*。

### 2. 特教外部連結 (External Link Schema)
```json
{
  "id": "link-sp-101",
  "title": "教育部全國特教通報網",
  "url": "https://www.set.edu.tw",
  "category": "行政公務系統",
  "description": "學童特教資格通報、特教學生身分查詢與鑑定安置。",
  "icon": "shield-check",
  "isPinned": true,
  "order": 1
}
```

## 前端 UI 元件結構 (Component Tree)
- `Navbar`：包含 Logo、導覽項目、公開下拉選單、🔒 校內特教業務按鈕、後台控制台鈕。
- `HomeView` (`#home`)：Hero Banner、4 大核心特教連結圖卡、公開網頁網格。
- `LinksView` (`#links`)：4 大核心連結展示、關鍵字搜尋框。
- `InternalView` (`#internal`)：密碼驗證頁面 (密碼: `8523984`)、解鎖後呈現校內業務網頁與個案表格。
- `PageView` (`#page/:slug`)：Markdown 內容渲染器與權限檢查。
- `AdminModal`：包含 `targetSection` (發布至公開專區 or 校內業務版面) 選擇器。

## 資安與託管規範 (Security & Deployment)
- **資安與個資**: 全站使用純前端瀏覽器記憶體與 LocalStorage，資料不傳輸至未授權第三方。
- **託管平臺**: GitHub Pages / Netlify（免費且無頻寬流量限制）。
