# 吉安國小特教行政網站 OpenSpec 提案說明 (Proposal)

## 專案簡介 (Project Overview)
「吉安國小特教行政網站」為花蓮縣吉安國民小學專屬之特教資訊門戶。專案採用 **OpenSpec (Spec-Driven Development, SDD)** 開發規範，將系統需求、架構設計與測試情境文檔化與機讀化，協助特教團隊與普通班導師高效率管理特教資源班、IEP 個別化教育計畫、轉介前介入與核心特教門戶跳轉。

## 專案目標 (Project Goals)
1. **特教核心連結與首頁導師專區 (Core Links & Teacher Hub)**：
   首頁展示 4 大官方核心特教門戶（教育部特教通報網、全國教師在職進修網、花蓮縣特教資源網、教育部特教資訊網-研習報名），並於下方設置「導師專區」，提供導師適性輔導與轉介指引。
2. **極簡導覽結構 (Streamlined Navigation)**：
   移除重複之頂部「特教核心連結」選單，提升使用者體驗與視覺俐落度。
3. **管理控制台與校內版面雙重密碼防護 (Dual Password Security)**：
   進入「校內特教業務版面」與「管理控制台」均強制實施密碼驗證（驗證密碼為 `8523984`），並於 UI 前台移除任何明文密碼提示文字，防範未授權存取與個資風險。
4. **零負擔託管與資安個資保護 (Zero-Leak Security & Hosting)**：
   託管於 GitHub Pages 平台（完全免費且無流量額度限制），所有特教資料皆採用純前端機制存取與加密。

- **特教資源班教師與行政人員 (Special Ed Staff)**：輸入密碼 `8523984` 開啟管理控制台，發布與管理公開/校內特教網頁。
- **家長與學生 (Parents & Students)**：瀏覽資源班簡介、公開特教核心門戶與宣導資料。
